What I’ve built

Viisi is a daily word game for iPhone: five letters, five words, one puzzle. CastLink shows how movies, TV shows, and actors connect, on the web and on iPhone. CSS Scratchpad is a Chrome extension for trying out CSS on any page without touching the source.

They’re for different people, but they follow the same rules: each one does a single job, none of them show ads or ask for an account, and none of them track you.
